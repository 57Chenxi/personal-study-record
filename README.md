# 自学机器学习学习记录

## 学习目标

通过理论总结和动手实践的方式，系统学习机器学习相关内容，并把学习过程公开记录下来，督促自己持续实践、复盘和改进。

## 单篇笔记模板

每篇章节笔记尽量包含：

- 本章核心问题
- 关键概念
- 原理推导或理解
- 代码实践
- 运行结果
- 遇到的问题
- 我的疑问
- 下一步计划
